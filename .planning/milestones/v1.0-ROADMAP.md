# Milestone v1.0: MVP

**Status:** SHIPPED 2026-02-15
**Phases:** 1-15
**Total Plans:** 51

## Overview

This roadmap delivered a browser-based multiplayer Shithead card game from zero to production deployment. The journey started with foundational infrastructure (project setup, WebSocket communication, room management), built the core game engine (deck dealing, turn system, special cards, endgame), added production-critical features (timing, reconnection), implemented the client UI, and finished with deployment. Each phase delivered a coherent, testable capability following the natural dependencies of multiplayer game architecture.

## Milestone Summary

**Key Decisions:**

- Room codes over matchmaking (friend-focused, keep it simple)
- No accounts (zero friction to start playing)
- Web app over native (cross-platform from day one)
- Bun as runtime (native TypeScript, fast WebSocket)
- Oracle Cloud Always Free tier for hosting (4 OCPU, 24GB RAM)
- Caddy for auto-HTTPS (zero-config Let's Encrypt)
- Infisical for secrets management (production credentials)
- Server-authoritative game state (prevents cheating)

**Issues Resolved:**

- WebSocket proxy in Docker requires host.docker.internal (not Docker service names)
- Bun node:http upgrade events don't fire properly (avoided custom WS proxy)
- Ngrok free tier blocks WebSocket on iOS mobile (cloudflared recommended)
- TypeScript composite projects need built .d.ts for cross-package type checking
- Vue-test-utils WeakMap incompatibility with Bun (2 pre-existing test failures)

**Issues Deferred:**

- iOS mobile WebSocket via ngrok (use cloudflared instead)
- Vue-test-utils Bun compatibility (2 test failures)
- Debug gamestate dev tooling (todo)

**Technical Debt Incurred:**

- Client App.test.ts has 2 pre-existing test failures (WeakMap issue)
- No milestone audit performed before archiving
