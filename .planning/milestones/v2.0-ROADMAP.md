# Milestone v2.0: UI + Discord

**Status:** SHIPPED 2026-02-21
**Phases:** 16-23
**Total Plans:** 26

## Overview

v2.0 expands the working v1.0 multiplayer card game with Discord Activity integration and mobile UX improvements. The journey prioritized risk mitigation (validate networking proxy early), established clean platform abstraction (prevent tech debt), integrated Discord OAuth2 and room management, then layered on UX polish (sound mute, playability highlights, mobile card improvements). All features work in both standalone web and Discord Activity modes from a single codebase.

## Milestone Summary

**Key Decisions:**
- Dual-mode architecture: adapter pattern keeps standalone web working alongside Discord Activity
- Risk-first ordering: validate Discord proxy (Phase 16) before building features
- Client copy of server pure functions: avoids cross-package dependency for card rules
- Retry timing: 5 retries with exponential backoff (~31s total) — 10 retries was too long
- Discord token exchange: application/x-www-form-urlencoded (not JSON)
- Discord SDK: dynamic import() via async startup — never static import in barrel
- instanceId-based auto-join: canonical Discord Activity room pattern
- Quick-029: simplified mobile card UI from category tabs to horizontal scroll after playtesting

**Issues Resolved:**
- Discord Activity fully working in production (proxy, OAuth2, auto-join, host migration)
- WebSocket reconnect on mobile tab return
- Edge browser compatibility (async IIFE + es2020 build target + dvh fallbacks)
- Mobile viewport scroll issues (dvh with vh fallback)
- Mobile touch zoom on double-tap
- Client test suite migrated from vue-test-utils to @testing-library/vue (resolved Bun WeakMap failures)

**Issues Deferred:**
- Mobile Discord testing (ngrok/cloudflared limitations on iOS)
- OAuth2 token refresh flow (7-day expiry)
- Spectator mode UI refinements

**Technical Debt Incurred:**
- Orphaned adapter injection keys (ConnectionAdapterKey, RoomAdapterKey provided but never consumed)
- Dead code: DiscordRoomAdapter.joinOrCreate() implemented but never called
- forcedIndices prop passed by PlayingPhase but not declared in PlayerCards defineProps
- Missing tests: cardRules.ts, PlayerCards.vue, PlayingPhase.vue, DiscordLobby.vue
- dangerouslyIgnoreUnhandledErrors: true in vitest config
