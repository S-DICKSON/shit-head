  <behavior>
**GameEngine.determinePlaySource(player: PlayerGameState, drawPileEmpty: boolean): PlaySource | null**

Input/Output mapping:
- Player with hand=[card1,card2], drawPileEmpty=false -> 'hand'
- Player with hand=[card1], drawPileEmpty=true -> 'hand' (hand cards always take priority)
- Player with hand=[], drawPileEmpty=false -> 'hand' (must draw before playing)
- Player with hand=[], drawPileEmpty=true, faceUp=[card1,card2] -> 'face-up'
- Player with hand=[], drawPileEmpty=true, faceUp=[], faceDown=[card1] -> 'face-down'
- Player with hand=[], drawPileEmpty=true, faceUp=[], faceDown=[] -> null (eliminated)

**GameEngine.checkPlayerElimination(player: PlayerGameState): boolean**

- Player with hand=[], faceUp=[], faceDown=[] -> true
- Player with hand=[card], faceUp=[], faceDown=[] -> false
- Player with hand=[], faceUp=[card], faceDown=[] -> false
- Player with hand=[], faceUp=[], faceDown=[card] -> false

**GameEngine.nextActivePlayerIndex(state: GameState, currentIndex: number): number**

- 3 players, P0 eliminated, current=2 -> returns 1 (skips P0)
- 3 players, P1 and P2 eliminated, current=0 -> returns 0 (only active player)
- 4 players, P1 eliminated, current=0 -> returns 2 (skips P1)
- 4 players, all eliminated except P3, current=0 -> returns 3
- 2 players, none eliminated, current=0 -> returns 1 (normal rotation)
- Must have loop limit (max attempts = playerCount) to prevent infinite loop

**GameEngine.findShithead(state: GameState): string | null**

- 3 players all with cards -> null (game continues)
- 3 players, 2 eliminated, 1 with cards -> returns playerId of the 1 with cards
- 2 players, 1 eliminated, 1 with cards -> returns playerId of the 1 with cards
- 4 players, 2 eliminated, 2 with cards -> null (game continues)

**GameEngine.playFromFaceUp(state: GameState, playerId: string, cardIndices: number[]): OperationResult&lt;GameState&gt;**

Validation errors (return success: false):
- `state.phase !== 'playing'` -> error: 'Can only play cards during playing phase', code: 'INVALID_ACTION'
- Player not found -> error: 'Player not found', code: 'PLAYER_NOT_FOUND'
- Player index !== state.currentPlayerIndex -> error: 'Not your turn', code: 'NOT_YOUR_TURN'
- determinePlaySource returns not 'face-up' -> error: 'Must play from correct source', code: 'INVALID_ACTION'
- cardIndices is empty -> error: 'Must play at least one card', code: 'INVALID_ACTION'
- Any index out of bounds for faceUp array -> error: 'Invalid card index', code: 'INVALID_ACTION'
- Duplicate indices -> error: 'Duplicate card indices', code: 'INVALID_ACTION'
- Cards at indices have different ranks -> error: 'All cards must have same rank', code: 'INVALID_ACTION'
- Card value too low (via canPlayOn) -> error: 'Card value too low', code: 'INVALID_ACTION'

Success behavior:
- Remove played cards from player's faceUp array (use filter with Set for O(1) lookup)
- Add played cards to end of discardPile
- NO auto-draw (draw pile is empty by definition when playing face-up)
- Check elimination: if player has zero total cards after play, they are eliminated
- If eliminated: advance turn via nextActivePlayerIndex, check findShithead
- If not eliminated: advance turn via nextActivePlayerIndex
- If findShithead returns a playerId: set state.phase = 'finished'
- Return new immutable GameState

Test scenarios:
1. Valid single face-up card play -> success, card moves to discard
2. Valid multi-card face-up play (2 same-rank cards) -> success
3. Play on empty discard pile from face-up -> success
4. Play lower card from face-up -> fails with 'Card value too low'
5. Not your turn -> fails with 'NOT_YOUR_TURN'
6. determinePlaySource returns 'hand' not 'face-up' -> fails
7. Invalid index -> fails
8. Player plays last face-up card(s), still has face-down -> not eliminated, turn advances
9. Player plays last face-up card(s), no face-down, no hand -> eliminated, check game end
10. Elimination triggers findShithead -> if only 1 player left with cards, phase = 'finished'
  </behavior>
