**1. Add PlaySource type to game.ts:**

Add the following type to `packages/shared/src/types/game.ts`:

```typescript
export type PlaySource = 'hand' | 'face-up' | 'face-down';
```

This type is used by the server to determine where a player must play from based on their current card state.

**2. Add new schemas to messages.ts:**

**Client-to-server schemas:**

1. `playFaceDownSchema` - Client selects a face-down card index to flip:
   ```
   { type: 'play-face-down', faceDownIndex: number }
   ```
   - `faceDownIndex`: `z.number().int().min(0)` (non-negative integer, no max since face-down count varies)

Add to the `clientMessageSchema` discriminated union.

**Server-to-client schemas:**

2. `faceDownResultSchema` - Server reveals result of blind face-down play:
   ```
   { type: 'face-down-result', playerId: string, card: Card, playable: boolean, currentPlayerIndex: number, discardPile: Card[], hand?: Card[], faceDownCount?: number, opponents?: OpponentView[] }
   ```
   - `playerId`: z.string() (who played the blind card)
   - `card`: cardSchema (the revealed card - all players see what was flipped)
   - `playable`: z.boolean() (whether the card was playable on the pile)
   - `currentPlayerIndex`: z.number() (next player's turn)
   - `discardPile`: z.array(cardSchema) (updated pile - contains card if playable, empty if not)
   - `hand`: z.array(cardSchema).optional() (updated hand for the player - present if they picked up)
   - `faceDownCount`: z.number().optional() (updated face-down count for the player)
   - `opponents`: z.array(opponentViewSchema).optional() (updated opponent views)

3. `playerEliminatedSchema` - Server broadcasts when a player drops out (all cards empty):
   ```
   { type: 'player-eliminated', playerId: string, nickname: string, currentPlayerIndex: number }
   ```
   - `playerId`: z.string() (eliminated player)
   - `nickname`: z.string() (for display)
   - `currentPlayerIndex`: z.number() (next active player after skip)

4. `gameOverSchema` - Server declares game over with the shithead:
   ```
   { type: 'game-over', shitheadId: string, shitheadNickname: string }
   ```
   - `shitheadId`: z.string() (the loser's player ID)
   - `shitheadNickname`: z.string() (the loser's nickname for display)

Add all three to the `serverMessageSchema` discriminated union.

**3. Add inferred types to messages.ts:**

Import the new schemas and add z.infer types:

```typescript
export type PlayFaceDownMessage = z.infer<typeof playFaceDownSchema>;
export type FaceDownResultMessage = z.infer<typeof faceDownResultSchema>;
export type PlayerEliminatedMessage = z.infer<typeof playerEliminatedSchema>;
export type GameOverMessage = z.infer<typeof gameOverSchema>;
```

**4. Add 'GAME_OVER' to error codes:**

Add `'GAME_OVER'` to the errorSchema code enum in messages.ts (for attempts to play after game ends). Also add to the ErrorCode type union in types/messages.ts.
