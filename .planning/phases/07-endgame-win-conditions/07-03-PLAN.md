<objective>
Implement GameEngine.playFaceDownBlind() for blind card play using TDD.

Purpose: Blind face-down play is the most complex endgame mechanic. The player selects a face-down card index without seeing its value, the server reveals it, and determines if it's playable. If playable, it goes on the pile. If not, the player picks up the ENTIRE pile INCLUDING the flipped card and returns to hand phase. This two-outcome mechanic is a critical TDD candidate with clear input/output contracts.

Output: Fully tested playFaceDownBlind method on GameEngine.

  <behavior>
**GameEngine.playFaceDownBlind(state: GameState, playerId: string, faceDownIndex: number): OperationResult&lt;GameState&gt;**

Return type includes an extra field on the data to indicate the result of the blind play:
```typescript
OperationResult<GameState & { blindPlayResult?: { card: Card; playable: boolean } }>
```

This extended return type allows the caller (WebSocket handler) to know which card was flipped and whether it was playable, so it can broadcast the face-down-result message. Alternatively, add a `lastBlindPlay` field to the returned GameState. The simplest approach: return an extended result type with an additional `blindPlayResult` property alongside the GameState.

Use this approach: Create a type `BlindPlayResult = { state: GameState; card: Card; playable: boolean }` and return `OperationResult<BlindPlayResult>`.

Validation errors (return success: false):
- `state.phase !== 'playing'` -> error: 'Can only play cards during playing phase', code: 'INVALID_ACTION'
- Player not found -> error: 'Player not found', code: 'PLAYER_NOT_FOUND'
- Player index !== state.currentPlayerIndex -> error: 'Not your turn', code: 'NOT_YOUR_TURN'
- determinePlaySource returns not 'face-down' -> error: 'Must play from correct source', code: 'INVALID_ACTION'
- faceDownIndex < 0 or >= player.faceDown.length -> error: 'Invalid face-down index', code: 'INVALID_ACTION'

Success path A (card IS playable):
- Remove flipped card from faceDown
- Add flipped card to end of discardPile
- Check elimination (all cards empty)
- If eliminated: advance turn via nextActivePlayerIndex, check findShithead
- If findShithead returns playerId: set phase = 'finished'
- If not eliminated: advance turn via nextActivePlayerIndex
- Return: `{ success: true, data: { state: newState, card: flippedCard, playable: true } }`

Success path B (card is NOT playable):
- Remove flipped card from faceDown
- Move entire discardPile + flippedCard into player's hand: `hand = [...state.discardPile, flippedCard]`
- Clear discardPile to []
- Player is NOT eliminated (they just picked up cards - they return to hand phase)
- Advance turn via nextActivePlayerIndex
- Return: `{ success: true, data: { state: newState, card: flippedCard, playable: false } }`

Empty pile edge case:
- If discardPile is empty when blind play happens, ANY card is playable (canPlayOn with no top card)
- This means blind play on empty pile always succeeds (path A)

Test scenarios:

**Validation tests:**
1. Wrong phase (swapping) -> fails
2. Not player's turn -> fails
3. Player has hand cards (source should be 'hand') -> fails with 'Must play from correct source'
4. Player has face-up cards (source should be 'face-up') -> fails
5. Invalid faceDownIndex (-1) -> fails
6. Invalid faceDownIndex (>= faceDown.length) -> fails
7. Player not found -> fails

**Playable card tests (path A):**
8. Blind card is higher than top of pile -> success, card on discard, faceDown count decreases
9. Blind card is equal to top of pile -> success (equal is playable)
10. Blind card on empty discard pile -> success (any card playable)
11. Blind card is a joker -> success (joker beats everything)
12. Player plays last face-down card, successfully -> player eliminated (all cards empty)
13. Elimination causes findShithead with 1 player remaining -> phase = 'finished'
14. Elimination but 2+ players remain -> game continues

**Unplayable card tests (path B):**
15. Blind card is lower than top of pile -> card + pile go to hand, discard cleared
16. Verify hand contains discardPile cards AND the flipped card
17. Verify discardPile is empty after pickup
18. Verify faceDown count decreases by 1
19. Turn advances to next player after pickup
20. After pickup, determinePlaySource on this player returns 'hand' (they have hand cards now)
21. Pickup when discard pile has many cards -> all go to hand

**Edge cases:**
22. Player with only 1 face-down card, blind play succeeds -> eliminated
23. Player with only 1 face-down card, blind play fails -> picks up pile, has hand cards, continues
24. 2-player game, blind play eliminates P0 -> P1 is shithead (last with cards), game ends
