<task type="auto">
  <name>Task 1: Add /api/token POST endpoint to Bun server</name>
  <files>packages/server/src/index.ts</files>
  <action>
Add a new route handler in the `fetch` function of `packages/server/src/index.ts`, positioned AFTER the `/health` route and BEFORE the `/game-ws` WebSocket upgrade route.

The route: `POST /api/token`

Implementation:
1. Check `url.pathname === '/api/token' && req.method === 'POST'`
2. Parse JSON body expecting `{ code: string }`
3. Validate `code` exists -- return 400 `{ error: 'Missing code' }` if not
4. Read `DISCORD_CLIENT_ID` and `DISCORD_CLIENT_SECRET` from `process.env`
5. If either is missing, log error and return 500 `{ error: 'Server configuration error' }`
6. POST to `https://discord.com/api/oauth2/token` with:
   - Header: `Content-Type: application/x-www-form-urlencoded` (NOT JSON -- Discord rejects JSON)
   - Body: `new URLSearchParams({ client_id, client_secret, grant_type: 'authorization_code', code })`
7. If Discord returns non-OK, log the error text and return the same status with `{ error: 'Token exchange failed' }`
8. Extract `access_token` from Discord response JSON
9. Return 200 with `{ access_token }` and `Content-Type: application/json`
10. Wrap entire handler in try/catch, return 500 `{ error: 'Internal server error' }` on unexpected errors

CRITICAL: Use `application/x-www-form-urlencoded` with `URLSearchParams` for the Discord API call. Discord's token endpoint rejects JSON bodies (returns 400).

All Response objects must include `Content-Type: application/json` header.
