  <name>Task 3: Guard /api/token against malformed JSON body</name>
  <files>packages/server/src/index.ts</files>
  <action>
In packages/server/src/index.ts, inside the `/api/token` POST handler (line 60-116), wrap the `req.json()` call (line 62) in its own try/catch that specifically catches JSON parse errors and returns 400.

Replace:
```typescript
const body = await req.json() as { code?: string };
```

With:
```typescript
let body: { code?: string };
try {
  body = await req.json() as { code?: string };
} catch {
  return new Response(JSON.stringify({ error: 'Invalid JSON body' }), {
    status: 400,
    headers: { 'Content-Type': 'application/json' },
  });
}
```

This ensures empty bodies, non-JSON content types, and malformed JSON all return 400 Bad Request with a descriptive error instead of falling through to the outer catch that returns 500 Internal Server Error.

Keep the existing `if (!body.code)` check (line 64) and the outer try/catch (line 109) unchanged — the outer catch still handles unexpected errors from the Discord API call.
