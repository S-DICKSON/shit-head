**Step 2: Create DiscordAuthAdapter**

Create `packages/client/src/platform/adapters/discord/DiscordAuthAdapter.ts` implementing the `AuthAdapter` interface.

The adapter implements the 4-step Discord OAuth2 flow:

1. **Constructor:** Takes `clientId: string`, creates `new DiscordSDK(clientId)` instance. Initialize `user` as `null` and `rawDiscordUser` as `null`.

2. **`authenticate()`:** Implements the full flow:
   - Step 1: `await this.sdk.ready()` -- handshake with Discord client
   - Step 2: `const { code } = await this.sdk.commands.authorize({ client_id: this.sdk.clientId, response_type: 'code', state: '', prompt: 'none', scope: ['identify'] })`
   - Step 3: `fetch('/.proxy/api/token', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ code }) })` -- exchange code for token via our server. Check `response.ok`, throw on failure.
   - Step 4: `await this.sdk.commands.authenticate({ access_token })` -- authenticate with Discord SDK
   - Store `auth.user` as rawDiscordUser (id, username, global_name, avatar)
   - Set `this.user = { id: auth.user.id, name: auth.user.global_name || auth.user.username }`

3. **`getCurrentUser()`:** Returns `this.user` (or null)

4. **`isAuthenticated()`:** Returns `this.user !== null`

5. **`signOut()`:** Sets `this.user = null` and `this.rawDiscordUser = null`

6. **`getDiscordUser()`:** (Discord-specific method, not in interface) Returns the raw Discord user object for avatar display. Type: `{ id: string; username: string; global_name: string | null; avatar: string | null } | null`

7. **`getSdk()`:** Returns the `DiscordSDK` instance (needed by other Discord adapters or future phases for event subscriptions)

Import `DiscordSDK` from `@discord/embedded-app-sdk`. Import `AuthAdapter` from `../../interfaces/AuthAdapter`.

Use `prompt: 'none'` (not 'consent') for seamless UX -- Discord handles consent when launching the Activity. Do NOT store access_token in localStorage -- keep it in memory only (it's short-lived).
