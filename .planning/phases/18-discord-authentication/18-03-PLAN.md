**Step 2: Wire Discord adapters in main.ts (`packages/client/src/main.ts`)**

Replace the `throw new Error('Discord adapters not implemented yet (Phase 18)')` line in the `else if (platform === 'discord')` branch with:

```typescript
} else if (platform === 'discord') {
  const discordAuth = new DiscordAuthAdapter(import.meta.env.VITE_DISCORD_CLIENT_ID);
  app.provide(AuthAdapterKey, discordAuth);
  app.provide(ConnectionAdapterKey, new DiscordConnectionAdapter());
  app.provide(RoomAdapterKey, new DiscordRoomAdapter());
}
```

Update the imports at the top of main.ts to include the three Discord adapters from `'./platform'`:
```typescript
import {
  detectPlatform,
  PlatformKey,
  AuthAdapterKey,
  ConnectionAdapterKey,
  RoomAdapterKey,
  WebAuthAdapter,
  WebConnectionAdapter,
  WebRoomAdapter,
  DiscordAuthAdapter,
  DiscordConnectionAdapter,
  DiscordRoomAdapter,
} from './platform'
```

IMPORTANT: The `DiscordAuthAdapter` constructor takes `import.meta.env.VITE_DISCORD_CLIENT_ID` as argument. This is a string injected by Vite at build time. If the env var is not set, it will be `undefined` -- the adapter will fail when trying to create the SDK. This is expected behavior (env vars must be configured before Discord mode works).

Do NOT add any auth flow invocation here. The `authenticate()` call will be triggered by the app's lifecycle in a future integration step or component mount. This plan only wires the adapters into Vue's injection system.
