  <name>Task 1: Add changeOrigin and allowedHosts to Vite config</name>
  <files>packages/client/vite.config.ts</files>
  <action>
Add two configuration options to vite.config.ts:

1. **Add changeOrigin: true to /game-ws proxy**
   - Location: Inside the '/game-ws' proxy config object (line 18-21)
   - Add: `changeOrigin: true,`
   - Why: The WebSocket handshake requires the Host header to match the target server (localhost:3000). Without changeOrigin, the proxy forwards Host: localhost:5173, causing the server to reject the WebSocket upgrade. With changeOrigin, the proxy rewrites Host: localhost:3000, allowing the handshake to complete.

2. **Add allowedHosts: true to server config**
   - Location: Inside the server config object (line 9-23)
   - Add: `allowedHosts: true,` (at top level of server config, alongside host, port, strictPort, etc.)
   - Why: Vite enforces hostname validation by default, blocking requests from non-localhost hostnames. This prevents ngrok tunnel URLs (e.g., abc123.ngrok.io) from accessing the dev server. Setting allowedHosts: true disables this validation, allowing any hostname to connect. This is safe for local dev and required for ngrok tunnels.

Final structure should look like:
```typescript
server: {
  host: '0.0.0.0',
  port: 5173,
  strictPort: true,
  allowedHosts: true,  // NEW - allows ngrok tunnel hostnames
  hmr: {
    path: '/__hmr',
  },
  proxy: {
    '/api': serverUrl,
    '/game-ws': {
      target: serverUrl.replace('http', 'ws'),
      ws: true,
      changeOrigin: true,  // NEW - rewrites Host header for WebSocket handshake
    },
  }
}
```

DO NOT change any other configuration. These are two single-line additions.
