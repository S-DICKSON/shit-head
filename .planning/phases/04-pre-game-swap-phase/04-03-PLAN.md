In `packages/server/src/websocket/handlers.ts`:

1. In the `start-game` handler's setTimeout callback (after dealing), set up swap callbacks on the room and start broadcasting:
   ```
   room.setSwapCallbacks({
     onTick: (timeRemaining) => {
       // Broadcast timer tick to all players in room
       const playerIds = room.getPlayerIds();
       for (const pid of playerIds) {
         const pWs = playerSockets.get(pid);
         if (pWs) {
           sendMessage(pWs, { type: 'swap-timer-tick', timeRemaining });
         }
       }
     },
     onReady: (playerId, readyPlayers) => {
       // Broadcast ready state to all players
       const playerIds = room.getPlayerIds();
       for (const pid of playerIds) {
         const pWs = playerSockets.get(pid);
         if (pWs) {
           sendMessage(pWs, { type: 'player-ready', playerId, readyPlayers });
         }
       }
     },
     onComplete: (reason) => {
       // Broadcast swap phase complete to all players
       const playerIds = room.getPlayerIds();
       for (const pid of playerIds) {
         const pWs = playerSockets.get(pid);
         if (pWs) {
           sendMessage(pWs, { type: 'swap-phase-complete', reason });
         }
       }
     },
   });
   ```
   Note: Set callbacks BEFORE sending game-dealt messages so they're ready when timer starts.

2. Add `case 'swap-cards':` handler:
   - Get roomCode from ws.data.roomCode, validate
   - Get room from manager.getRoom(roomCode), validate
   - Call `room.swapCards(ws.data.playerId, message.handIndex, message.faceUpIndex)`
   - On failure: sendMessage with error
   - On success: Send per-player `swap-cards-updated` to ALL players (including sender, since server is authoritative):
     ```
     const playerIds = room.getPlayerIds();
     for (const playerId of playerIds) {
       const view = room.getPlayerView(playerId);
       const playerWs = playerSockets.get(playerId);
       if (view && playerWs) {
         sendMessage(playerWs, {
           type: 'swap-cards-updated',
           hand: view.hand,
           faceUp: view.faceUp,
           opponents: view.opponents,
         });
       }
     }
     ```

3. Add `case 'ready-up':` handler:
   - Get roomCode and room (same pattern as swap-cards)
   - Call `room.markPlayerReady(ws.data.playerId)`
   - On failure: sendMessage with error
   - On success: No action needed (Room's onReady callback handles broadcasting)
