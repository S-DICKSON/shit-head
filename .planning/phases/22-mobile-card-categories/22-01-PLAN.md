<objective>
Add normal/power card category navigation with horizontal carousel to the mobile grouped card view, so players with large hands can quickly find and play the right cards.

Purpose: When players have 6+ cards on mobile, the current vertical list of grouped cards becomes hard to scan. Splitting into "Normal" and "Power" categories with tab navigation and a horizontal carousel makes it faster to locate specific card types (especially power cards like 2, 7, 8, 10, Joker that have special game effects).

Output: New `useCardCategories` composable and updated `PlayerCards.vue` with category tabs, CSS scroll-snap carousel, gold power card styling, and empty category handling.
</objective>

**Exports:**

1. `isPowerCard(card: Card): boolean` — Pure function. Power card ranks are `2`, `7`, `8`, `10`, and Joker (kind === 'joker'). Use a `Set(['2', '7', '8', '10'])` for O(1) rank lookup. Note: this differs from server-side `isSpecialCard()` which only covers 2, 8, 10 — the `7` and Joker are power cards for UI categorization purposes.

2. `CardCategory` type — `'power' | 'normal'`

3. `useCardCategories(hand: Ref<Card[]>)` composable that returns:
   - All properties from `useCardGrouping(hand)` passed through explicitly: `groupedCards`, `selectedCounts`, `incrementSelection`, `decrementSelection`, `selectedIndices`, `hasGroupSelection`, `clearGroupSelection`, `getSelectedCount`
   - `activeCategory: Ref<CardCategory>` — starts as `'normal'`
   - `powerGroups: ComputedRef<CardGroup[]>` — `groupedCards.value.filter(g => g.cards.some(c => isPowerCard(c)))`. A group is "power" if ANY card in it is a power card (this works because groups are by rank, so all cards in a group share the same rank — either all power or all normal).
   - `normalGroups: ComputedRef<CardGroup[]>` — `groupedCards.value.filter(g => g.cards.every(c => !isPowerCard(c)))`
   - `powerCount: ComputedRef<number>` — total card count across power groups: `powerGroups.value.reduce((acc, g) => acc + g.count, 0)`
   - `normalCount: ComputedRef<number>` — total card count across normal groups: same pattern
   - `activeGroups: ComputedRef<CardGroup[]>` — returns `powerGroups` or `normalGroups` based on `activeCategory`
   - `switchCategory(cat: CardCategory): void` — sets `activeCategory.value = cat`

Import `Card` type from `@shit-head/shared`. Import `CardGroup` and `useCardGrouping` from `./useCardGrouping`. Import `computed`, `ref`, `type Ref`, `type ComputedRef` from `vue`.

Do NOT add a watcher for clearing selection here — that wiring belongs in the component (Task 2) because `clearGroupSelection` is returned from useCardGrouping which this composable re-exports.

   }
