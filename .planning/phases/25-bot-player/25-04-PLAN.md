    ```html
      title="Bot player"
    >&#129302;</span>
    ```
    Note: &#129302; is the robot face emoji. If that causes issues, use the text "[BOT]" instead with `class="text-xs font-bold text-gray-400 uppercase"`.

    - The `(You)` span already has `v-if="player.id === playerId"` — bots will never match playerId, so this is fine.
    - The rename button has `v-if="player.id === playerId && !isRenaming"` — also fine, bots won't match.

    c. Add a Remove button for bots (host only). After the shithead marker span, add:
    ```html

      class="px-2 py-1 text-xs font-medium text-red-600 hover:text-red-700 bg-red-50 hover:bg-red-100 border border-red-200 rounded transition-colors"

    >
      Remove
    </button>
    ```

    ```html
      @click="addBot"
    >
      + Add Bot
    </button>
    ```
