**In `packages/client/index.html`:**
Update the viewport meta tag to include `viewport-fit=cover`:
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">
```
This is REQUIRED for `env(safe-area-inset-*)` to return non-zero values on iOS.

**In `packages/client/src/style.css`:**
Add safe area CSS custom properties after the Tailwind import:
```css
@import "tailwindcss";

:root {
  --safe-top: env(safe-area-inset-top, 0px);
  --safe-right: env(safe-area-inset-right, 0px);
  --safe-bottom: env(safe-area-inset-bottom, 0px);
  --safe-left: env(safe-area-inset-left, 0px);
}
```

**In `packages/client/src/App.vue`:**
Apply safe area padding at the root level ONLY (per research pitfall #4 — don't apply at multiple levels):
```vue
<template>
  <div
    class="min-h-screen bg-green-900"
    :style="{
      paddingTop: 'var(--safe-top)',
      paddingBottom: 'var(--safe-bottom)',
      paddingLeft: 'var(--safe-left)',
      paddingRight: 'var(--safe-right)',
    }"
  >
    <RouterView />
    <NotificationToast />
    <ConnectionStatus />
  </div>
</template>
```
On devices without notches, `env()` returns 0px, so this has zero visual impact on desktop or non-notch mobile.

IMPORTANT: Do NOT add safe area padding to any inner components. The root App.vue handles it. Inner components using `min-h-screen` should use `min-h-[calc(100dvh-var(--safe-top)-var(--safe-bottom))]` if they need full height, or just use `flex-1` within the parent container. Actually, since App.vue is already `min-h-screen` and now has padding, inner components using `min-h-screen` may need adjustment. The simplest approach: use `min-h-[100dvh]` on the App.vue root with safe area padding, so inner components can just use `flex-1` or `h-full` naturally.

Alternative simpler approach for App.vue if the above causes layout issues:
```vue
<template>
  <div
    class="bg-green-900"
    style="min-height: 100dvh; padding-top: var(--safe-top); padding-bottom: var(--safe-bottom); padding-left: var(--safe-left); padding-right: var(--safe-right);"
  >
    <RouterView />
    <NotificationToast />
    <ConnectionStatus />
  </div>
</template>
```
Use `100dvh` (dynamic viewport height) which accounts for mobile browser chrome.
