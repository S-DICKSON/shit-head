**CardRules.ts - isSpecialCard(card: Card): boolean**

Returns true if the card is a special card (rank 2, 8, or 10). Jokers are NOT special cards (they follow normal high-value ordering). 7 is NOT a special card itself (it follows normal ordering when played) - its constraint applies to the NEXT player.

Input/Output:
- `{ kind: 'standard', rank: '2', suit: 'hearts' }` -> true
- `{ kind: 'standard', rank: '8', suit: 'hearts' }` -> true
- `{ kind: 'standard', rank: '10', suit: 'hearts' }` -> true
- `{ kind: 'standard', rank: '7', suit: 'hearts' }` -> false
- `{ kind: 'standard', rank: 'K', suit: 'hearts' }` -> false
- `{ kind: 'joker', id: 1 }` -> false

**CardRules.ts - getEffectiveTopCard(discardPile: Card[]): Card | null**

Returns the "effective" top card of the pile, looking through any 8s on top to find the non-8 card beneath. Returns null if pile is empty or contains only 8s (meaning any card can be played).

Input/Output:
- `[]` -> null (empty pile)
- `[7H]` -> 7H (single non-8 card)
- `[5H, 8S]` -> 5H (look through one 8)
- `[KD, 8H, 8S]` -> KD (look through two 8s)
- `[8H, 8S, 8C]` -> null (all 8s, any card valid)
- `[7H, KD]` -> KD (top is non-8, return it directly)
- `[3H, 8H, 8S, 8C, 8D]` -> 3H (look through four 8s)

Implementation: Iterate backwards from top of pile (pile.length - 1), skip any card that is `kind === 'standard' && rank === '8'`, return the first non-8 card found. If none found, return null.

**CardRules.ts - canPlayOnPile(playedCard: Card, discardPile: Card[]): boolean**

Determines if a card can be legally played on the current discard pile. Replaces the simple `canPlayOn` from CardComparison for gameplay use.

Rules in order of precedence:
1. Empty pile (discardPile.length === 0): ANY card can be played -> return true
2. Played card is rank '2': ALWAYS playable (2 resets pile) -> return true
3. Played card is rank '10': ALWAYS playable (10 burns pile) -> return true
4. Played card is rank '8': ALWAYS playable (8 is invisible) -> return true
5. Effective top card is null (pile is all 8s): ANY card can be played -> return true
6. Effective top card is rank '7' (7-constraint): played card must have rank value <= rank value of 7 (i.e., ranks 2-7 or special cards already handled above) -> use getRankValue comparison
7. Normal ordering: played card rank value >= effective top card rank value -> use getRankValue comparison

IMPORTANT: For rule 6 (7-constraint), the check is `getRankValue(playedCard) <= getRankValue(seven)`. Since 2, 8, 10 are handled by rules 2-4 before reaching rule 6, only normal cards (3, 4, 5, 6, 7, 9, J, Q, K, A, Joker) need the comparison. Cards 3-7 pass. Cards 9+ fail. This is correct per game rules.

Input/Output for key scenarios:
- `(2H, [KD])` -> true (2 resets)
- `(10H, [AD])` -> true (10 burns)
- `(8S, [3H])` -> true (8 always playable)
- `(KD, [])` -> true (empty pile)
- `(5H, [7D])` -> true (5 <= 7, 7-constraint satisfied)
- `(9H, [7D])` -> true (9 > 7, BUT wait - 7 constrains next player, not current player. When the effective top is 7, you MUST play <= 7. So 9 on 7 is INVALID) -> false
- `(JH, [7D])` -> false (J > 7, fails 7-constraint)
- `(7H, [7D])` -> true (7 <= 7, same value)
- `(AH, [7D])` -> false (A > 7, fails 7-constraint)
- `(3H, [7D])` -> true (3 < 7)
- `(Joker, [7D])` -> false (Joker value 999 > 7 value 4, fails 7-constraint)
- `(KD, [8H, 5S])` -> true (effective top is 5, K >= 5)
- `(3H, [8H, 5S])` -> false (effective top is 5, 3 < 5)
- `(KD, [7H, 8S])` -> false (effective top is 7 [looking through 8], K > 7, fails 7-constraint)
- `(5H, [7H, 8S])` -> true (effective top is 7, 5 <= 7)
- `(KD, [KS])` -> true (K >= K, equal allowed)
- `(QH, [KS])` -> false (Q < K)
- `(Joker, [AD])` -> true (Joker >= A in normal ordering)
- `(3H, [Joker])` -> false (3 < Joker)

**CardRules.ts - detectBurn(discardPile: Card[]): { isBurn: boolean; reason?: 'ten' | 'four-of-a-kind' }**

Checks if the current discard pile should trigger a burn.

Rules:
1. If pile is empty: `{ isBurn: false }`
2. If top card is rank '10': `{ isBurn: true, reason: 'ten' }`
3. If four-of-a-kind on top (with 8s invisibility): `{ isBurn: true, reason: 'four-of-a-kind' }`
4. Otherwise: `{ isBurn: false }`

Four-of-a-kind detection with 8s invisibility:
- Get the top card's rank
- If top card rank is '8': count consecutive 8s from top. If >= 4, burn.
- If top card rank is NOT '8': iterate backwards from top, skip 8s, count consecutive cards of same rank. If >= 4, burn.

Input/Output:
- `[]` -> `{ isBurn: false }` (empty)
- `[3H, 10S]` -> `{ isBurn: true, reason: 'ten' }` (10 on top)
- `[KH, KD, KC, KS]` -> `{ isBurn: true, reason: 'four-of-a-kind' }` (four kings)
- `[3H, KH, KD, KC, KS]` -> `{ isBurn: true, reason: 'four-of-a-kind' }` (four kings on top)
- `[KH, KD, KC]` -> `{ isBurn: false }` (only three kings)
- `[8H, 8D, 8C, 8S]` -> `{ isBurn: true, reason: 'four-of-a-kind' }` (four 8s)
- `[2H, 8S, 2D, 8C, 2S, 2C]` -> `{ isBurn: true, reason: 'four-of-a-kind' }` (four 2s, 8s invisible)
- `[5H, 2H, 2D, 8S, 2S, 2C]` -> `{ isBurn: true, reason: 'four-of-a-kind' }` (four 2s, 8 invisible in middle)
- `[KH, KD, 8S, KC, KS]` -> `{ isBurn: true, reason: 'four-of-a-kind' }` (four kings, 8 invisible)
- `[KH, KD, 8S, KC]` -> `{ isBurn: false }` (only three kings visible)
- `[8H, 8D, 8C]` -> `{ isBurn: false }` (only three 8s)
- `[QH, 8S, 8C, KH]` -> `{ isBurn: false }` (K on top, only 1 king)
- `[10H]` -> `{ isBurn: true, reason: 'ten' }` (single 10)

Note: When a Joker is on top, it's treated as a regular card for burn counting - four jokers could theoretically burn but there are only 2 in the deck so it's impossible. No special handling needed.

   ```typescript
   import type { Card, Rank } from '@shit-head/shared';
   import { getRankValue } from './CardComparison';

   const SPECIAL_RANKS: ReadonlySet<string> = new Set(['2', '8', '10']);

   export function isSpecialCard(card: Card): boolean {
     return card.kind === 'standard' && SPECIAL_RANKS.has(card.rank);
   }

   export function getEffectiveTopCard(discardPile: Card[]): Card | null {
     for (let i = discardPile.length - 1; i >= 0; i--) {
       const card = discardPile[i];
       if (card.kind === 'standard' && card.rank === '8') continue;
       return card;
     }
     return null;
   }

   export function canPlayOnPile(playedCard: Card, discardPile: Card[]): boolean {
     // Empty pile: anything goes
     if (discardPile.length === 0) return true;

     // Special cards always playable
     if (playedCard.kind === 'standard') {
       if (playedCard.rank === '2') return true;
       if (playedCard.rank === '10') return true;
       if (playedCard.rank === '8') return true;
     }

     // Get effective top card (looking through 8s)
     const effectiveTop = getEffectiveTopCard(discardPile);

     // If pile is all 8s, anything goes
     if (effectiveTop === null) return true;

     // 7-constraint: if effective top is 7, must play <= 7
     if (effectiveTop.kind === 'standard' && effectiveTop.rank === '7') {
       return getRankValue(playedCard) <= getRankValue(effectiveTop);
     }

     // Normal ordering: played card must be >= effective top
     return getRankValue(playedCard) >= getRankValue(effectiveTop);
   }

   export function detectBurn(discardPile: Card[]): { isBurn: boolean; reason?: 'ten' | 'four-of-a-kind' } {
     if (discardPile.length === 0) return { isBurn: false };

     const topCard = discardPile[discardPile.length - 1];

     // 10 always burns
     if (topCard.kind === 'standard' && topCard.rank === '10') {
       return { isBurn: true, reason: 'ten' };
     }

     // Four-of-a-kind detection
     if (topCard.kind !== 'standard') return { isBurn: false };

     const targetRank = topCard.rank;
     let count = 0;

     for (let i = discardPile.length - 1; i >= 0; i--) {
       const card = discardPile[i];
       if (card.kind !== 'standard') break;

       if (targetRank === '8') {
         // When counting 8s, only 8s count
         if (card.rank === '8') {
           count++;
         } else {
           break;
         }
       } else {
         // For non-8 ranks, 8s are invisible (skip them)
         if (card.rank === '8') continue;
         if (card.rank === targetRank) {
           count++;
         } else {
           break;
         }
       }
     }

     if (count >= 4) {
       return { isBurn: true, reason: 'four-of-a-kind' };
     }

     return { isBurn: false };
   }
   ```
