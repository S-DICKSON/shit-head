Update to:

1. Import `detectPlatform` from `@/platform/detection`
2. Import injection keys: `PlatformKey`, `AuthAdapterKey`, `ConnectionAdapterKey`, `RoomAdapterKey` from `@/platform/keys`
3. Import web adapters: `WebAuthAdapter`, `WebConnectionAdapter`, `WebRoomAdapter` from their respective files under `@/platform/adapters/web/`

4. After `createApp(App)`, before `app.use(router)`:
   - Call `const platform = detectPlatform()`
   - Log: `console.log('[Platform] Running in ${platform} mode')`
   - `app.provide(PlatformKey, platform)`
   - If platform is 'web':
     - `app.provide(AuthAdapterKey, new WebAuthAdapter())`
     - `app.provide(ConnectionAdapterKey, new WebConnectionAdapter())`
     - `app.provide(RoomAdapterKey, new WebRoomAdapter())`
   - If platform is 'discord':
     - Throw `new Error('Discord adapters not implemented yet (Phase 18)')` — this is a clear signal for Phase 18 work

5. Keep existing `app.use(router)` and `app.mount('#app')` after provider setup.

IMPORTANT: Do NOT modify any other files. The existing components still use `useGameSocket()` directly — that is correct for now. Components will migrate to inject-based adapters incrementally in future phases as needed. The adapters are PROVIDED but not yet CONSUMED. This is intentional: it validates the wiring without risking v1.0 breakage.

Do NOT add `if (isDiscord)` checks to any game components. Do NOT modify useGameSocket.ts. Do NOT modify router.ts. Only main.ts changes.
