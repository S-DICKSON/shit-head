  <action>
Create the platform detection and interface foundation. All new files under `packages/client/src/platform/`.

**detection.ts:**
- Export `type Platform = 'discord' | 'web'`
- Export `function detectPlatform(): Platform` that uses synchronous iframe check (`window.self !== window.top`) combined with Discord query params (`frame_id`, `instance_id`). Both conditions must be true for 'discord'; default to 'web'.
- No async detection needed for Phase 17 (async SDK validation deferred to Phase 18).

**interfaces/AuthAdapter.ts:**
- Export `interface AuthAdapter` with methods:
  - `getCurrentUser(): Promise<{ id: string; name: string } | null>` — get current authenticated user
  - `authenticate(): Promise<void>` — trigger auth flow (no-op for web)
  - `isAuthenticated(): boolean` — check auth status
  - `signOut(): Promise<void>` — clear auth state
- Keep interface platform-agnostic. No Discord-specific types.

**interfaces/ConnectionAdapter.ts:**
- Export `interface ConnectionAdapter` with:
  - `readonly status: Ref<string>` — reactive connection status (import Ref from vue)
  - `send(message: ClientMessage): void` — send typed message
  - `onMessage(handler: (msg: ServerMessage) => void): () => void` — register handler, return unsubscribe
  - `close(): void` — close connection
  - `open(): void` — open/reconnect
- Import `ClientMessage` and `ServerMessage` from `@shit-head/shared`.
- Import `Ref` from `vue`.

**interfaces/RoomAdapter.ts:**
- Export `interface RoomAdapter` with:
  - `createRoom(nickname: string): void` — create a new room
  - `joinRoom(code: string, nickname: string): void` — join by code
  - `leaveRoom(): void` — leave current room
- These map to the WebSocket message types already in the shared package. Keep it simple — room operations are thin wrappers around send().

**keys.ts:**
- Import `InjectionKey` from `vue`
- Import all adapter interfaces and Platform type
- Export typed injection keys:
  - `PlatformKey: InjectionKey<Platform>`
  - `AuthAdapterKey: InjectionKey<AuthAdapter>`
  - `ConnectionAdapterKey: InjectionKey<ConnectionAdapter>`
  - `RoomAdapterKey: InjectionKey<RoomAdapter>`
- Each key uses `Symbol('descriptiveName')` for debugging

All files use TypeScript, no `any` types. Use JSDoc comments on interface methods.

  <action>
Implement web-specific adapters that wrap existing v1.0 functionality. These adapters delegate to existing code — they do NOT reimplement logic.

**adapters/web/WebAuthAdapter.ts:**
- `implements AuthAdapter`
- `getCurrentUser()`: reads `shithead-player-id` and `shithead-player-nickname` from localStorage. Returns `{ id, name }` or null if either missing.
- `authenticate()`: no-op for standalone web (auth happens implicitly via server-assigned playerId on room create/join)
- `isAuthenticated()`: returns `localStorage.getItem('shithead-player-id') !== null`
- `signOut()`: removes `shithead-player-id`, `shithead-player-nickname`, `shithead-room-code` from localStorage

**adapters/web/WebConnectionAdapter.ts:**
- `implements ConnectionAdapter`
- Constructor or initialization calls `useGameSocket()` to get the singleton socket instance
- Delegates all methods to the socket instance:
  - `get status()` returns `this.socket.status`
  - `send(message)` calls `this.socket.send(message)`
  - `onMessage(handler)` calls `this.socket.onMessage(handler)` and returns the unsubscribe function
  - `close()` calls `this.socket.close()`
  - `open()` calls `this.socket.open()`
- IMPORTANT: This is a thin wrapper. The useGameSocket composable already handles all WebSocket logic, reconnection, state management. Do NOT duplicate any of that logic.
- Import useGameSocket from `@/composables/useGameSocket`

**adapters/web/WebRoomAdapter.ts:**
- `implements RoomAdapter`
- Constructor or initialization calls `useGameSocket()` to get the singleton socket instance
- `createRoom(nickname)`: calls `this.socket.send({ type: 'create-room', nickname })`
- `joinRoom(code, nickname)`: calls `this.socket.send({ type: 'join-room', code, nickname })`
- `leaveRoom()`: calls `this.socket.send({ type: 'leave-room' })`
- This is an extremely thin wrapper — just maps method calls to typed WebSocket messages.

**index.ts (barrel export):**
- Re-export everything from detection, keys, and all interfaces
- Re-export all web adapters
- This allows clean imports like `import { detectPlatform, WebAuthAdapter } from '@/platform'`
