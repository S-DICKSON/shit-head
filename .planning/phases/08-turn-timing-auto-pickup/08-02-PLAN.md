    Add `room.setTurnTimerCallbacks(...)` registration:

    ```typescript
    room.setTurnTimerCallbacks({
      onTick: (timeRemaining, currentPlayerIndex) => {
        // Broadcast turn timer tick to ALL players
        const playerIds = room.getPlayerIds();
        for (const pid of playerIds) {
          const pWs = playerSockets.get(pid);
          if (pWs) {
            sendMessage(pWs, {
              type: 'turn-timer-tick',
              timeRemaining,
              currentPlayerIndex,
            });
          }
        }
      },
      onTimeout: (timedOutPlayerId) => {
        // Execute auto-play for the timed-out player
        const result = room.autoPlayOnTimeout(timedOutPlayerId);
        if (!result.success) return;

        const autoPlayData = result.data;
        const playerIds = room.getPlayerIds();

        if (autoPlayData.wasBlindPlay) {
          // Face-down auto-play: broadcast face-down-result to all players
          for (const pid of playerIds) {
            const view = room.getPlayerView(pid);
            const pWs = playerSockets.get(pid);
            if (view && pWs) {
              sendMessage(pWs, {
                type: 'face-down-result',
                playerId: timedOutPlayerId,
                card: autoPlayData.blindCard!,
                playable: autoPlayData.blindPlayable!,
                currentPlayerIndex: view.currentPlayerIndex,
                discardPile: view.discardPile,
                hand: view.hand,
                faceDownCount: view.faceDownCount,
                opponents: view.opponents,
              });
            }
          }
        } else {
          // Hand or face-up auto-play: broadcast card-played or pile-pickup
          const gameState = room.getGameState();
          if (!gameState) return;

          // Determine if it was a pile pickup (discard pile is empty after pickup)
          // by checking if the previous discard pile was non-empty and now is empty
          // Simpler: check if the auto-play resulted in an empty discard pile AND the player's hand grew
          // Actually, the cleanest approach: check gameState directly
          // If the player's hand grew significantly (more than discardPile had), it was a pickup.
          // Simplest: Use the gameState. If discardPile is empty and it wasn't a burn scenario,
          // it's a pickup. But burns also clear the pile.
          //
          // Best approach: Send per-player views after any auto-play. Use card-played for plays
          // and pile-pickup for pickups. But we don't easily know which happened.
          //
          // PRAGMATIC APPROACH: After auto-play, just send per-player views as a generic state update.
          // We can use the 'card-played' message type for plays (with the played cards) or
          // 'pile-pickup' for pickups. Since we're in the timeout handler and the state is already
          // updated, we need to determine what happened.
          //
          // The AutoPlayResult from GameEngine tells us the final state but not what action was taken.
          // To differentiate: check if the timed-out player's hand count increased dramatically
          // (pickup) vs. the discard pile changed (play). This is fragile.
          //
          // SIMPLEST CORRECT APPROACH: Send turn-changed + per-player card-played/pile-pickup.
          // Since the state is already updated, broadcast generic per-player views:
          for (const pid of playerIds) {
            const view = room.getPlayerView(pid);
            const pWs = playerSockets.get(pid);
            if (view && pWs) {
              // Send card-played with current state (works for both play and pickup scenarios
              // since the client just needs the updated state)
              sendMessage(pWs, {
                type: 'card-played',
                playerId: timedOutPlayerId,
                cards: [], // Auto-play doesn't expose which card was played (no visual distinction per CONTEXT.md)
                currentPlayerIndex: view.currentPlayerIndex,
                drawPileCount: view.drawPileCount,
                discardPile: view.discardPile,
                hand: view.hand,
                opponents: view.opponents,
              });
            }
          }
        }
      },
    });
    ```

    Note: The auto-play broadcast uses `card-played` for non-blind plays because per the locked decision there is NO visual distinction between manual play and auto-play. The client sees the same card-played event whether it was manual or auto. The `cards: []` is acceptable since the state update (hand, opponents, discardPile) already reflects what happened. If the executor finds this insufficient, they can snapshot the discard pile before auto-play to extract played cards, but per the deferred decisions, no "auto-played" label is shown.

    **Alternative cleaner approach for the executor:** Before calling `room.autoPlayOnTimeout()`, snapshot the discard pile length. After the call, check if discard pile grew (play) or shrank to 0 (pickup/burn). If discard pile is now empty and was non-empty before, it's likely a pickup. This lets the handler send `pile-pickup` vs `card-played` accurately. But since there's no visual distinction required, using `card-played` for everything is acceptable.
