    **GREEN phase — Implement autoPlayOnTimeout:**

    Add a static method `autoPlayOnTimeout` to the `GameEngine` class in `packages/server/src/game/GameEngine.ts`:

    ```typescript
    static autoPlayOnTimeout(
      state: GameState,
      playerId: string
    ): OperationResult<GameState> | OperationResult<BlindPlayResult> {
    ```

    Implementation logic:
    1. Validate phase is 'playing', return error if not.
    2. Find player by playerId, return error if not found.
    3. Call `this.determinePlaySource(player, state.drawPile.length === 0)` to get play source.
    4. If play source is `'hand'`:
       - Iterate player.hand, collect indices where `canPlayOnPile(card, state.discardPile)` returns true.
       - If valid indices exist: pick random index via `Math.floor(Math.random() * validIndices.length)`, call `this.playCards(state, playerId, [validIndices[randomIdx]])`.
       - If no valid indices: call `this.pickupPile(state, playerId)`.
    5. If play source is `'face-up'`:
       - Same logic but using player.faceUp and `this.playFromFaceUp(state, playerId, [validIndices[randomIdx]])`.
       - If no valid face-up cards: call `this.pickupPile(state, playerId)`.
    6. If play source is `'face-down'`:
       - Pick random index: `Math.floor(Math.random() * player.faceDown.length)`.
       - Call `this.playFaceDownBlind(state, playerId, randomIndex)`.
    7. If play source is `null` (eliminated): return error 'Player has no cards to play'.

    **IMPORTANT:** The return type is a union because face-down returns `BlindPlayResult` while others return `GameState`. Use overloads or a single union return type. Simplest approach: return `OperationResult<GameState | BlindPlayResult>` and let the caller inspect the result.

    Actually, for cleaner typing, make the method always return `OperationResult<{ state: GameState; wasBlindPlay: boolean; blindCard?: Card; blindPlayable?: boolean }>`. This normalizes the result:
    - For hand/face-up plays: extract `data` from playCards/playFromFaceUp/pickupPile result, wrap as `{ state: data, wasBlindPlay: false }`.
    - For face-down plays: extract BlindPlayResult, wrap as `{ state: result.state, wasBlindPlay: true, blindCard: result.card, blindPlayable: result.playable }`.

    **Simpler alternative (recommended):** Keep the existing return types. For hand and face-up, autoPlayOnTimeout returns `OperationResult<GameState>`. For face-down, it returns `OperationResult<BlindPlayResult>`. The caller (Room.ts in plan 02) will need to check play source to know the return type. Since this is a static method used only by Room, use a single return type:

    ```typescript
    type AutoPlayResult = {
      state: GameState;
      wasBlindPlay: boolean;
      blindCard?: Card;
      blindPlayable?: boolean;
    };

    static autoPlayOnTimeout(
      state: GameState,
      playerId: string
    ): OperationResult<AutoPlayResult>
    ```

    For hand/face-up plays that call playCards/playFromFaceUp/pickupPile:
    - Extract the returned GameState from result.data
    - Return `{ state: gameState, wasBlindPlay: false }`

    For face-down plays:
    - Extract BlindPlayResult from playFaceDownBlind result.data
    - Return `{ state: blindResult.state, wasBlindPlay: true, blindCard: blindResult.card, blindPlayable: blindResult.playable }`

    Export the `AutoPlayResult` type so Room.ts can use it.
