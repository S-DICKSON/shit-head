   - Minimal config, set install.frozen to false for initial setup

   - name: "@shit-head/shared"
   - version: "0.0.1"
   - type: "module"
   - main: "src/index.ts"
   - types: "src/index.ts"
   - No dependencies (pure types package for now)

6. **packages/shared/tsconfig.json**:

<task type="auto">
  <name>Task 2: Create server package with Bun HTTP server and WebSocket scaffold</name>
  <files>
    packages/server/package.json
    packages/server/tsconfig.json
    packages/server/src/index.ts
  </files>
  <action>
Create the server package:

1. **packages/server/package.json**:
   - name: "@shit-head/server"
   - version: "0.0.1"
   - type: "module"
   - scripts: { "dev": "bun --watch src/index.ts", "start": "bun src/index.ts", "test": "bun test" }
   - dependencies: { "@shit-head/shared": "workspace:*" }
   - No additional dependencies needed — Bun provides HTTP server and WebSocket natively

2. **packages/server/tsconfig.json**:
   - extends root tsconfig
   - include: ["src"]
   - compilerOptions: { composite: true, rootDir: "src", outDir: "dist" }
   - references: [{ path: "../shared" }]

3. **packages/server/src/index.ts**:
   - Import APP_VERSION from @shit-head/shared to prove workspace linking works
   - Create Bun.serve() with:
     - port: Number(process.env.PORT) || 3000
     - fetch handler:
       - GET /health → returns JSON { status: "ok", version: APP_VERSION, uptime: process.uptime() }
       - GET /ws → upgrades to WebSocket (scaffold only, returns upgrade success or 500)
       - Default → returns 404 "Not Found"
     - websocket handler (scaffold):
       - open: log "Client connected"
       - message: echo back the message (basic echo for now)
       - close: log "Client disconnected"
   - Log startup: `console.log("Server listening on port ${server.port}")`
   - Use the WebSocket data typing pattern from research: `type WebSocketData = { userId: string }`

Then run `bun install` from root to link the new package. Update root tsconfig.json references to include packages/server if not already there.
  </action>
  <verify>
    Run: `bun run --cwd packages/server start` — server starts on port 3000.
    Run: `curl http://localhost:3000/health` — returns JSON with status "ok" and version "0.0.1".
    Run: `curl http://localhost:3000/nonexistent` — returns 404.
    Kill the server process after verification.
  </verify>
  <done>Server package exists with working Bun HTTP server. Health endpoint returns version from shared package (proving workspace linking). WebSocket upgrade scaffold is in place. Server starts on configurable port (default 3000).</done>
</task>
