    1. Install dependencies: `cd packages/client && bun add @vueuse/core vue-router`

    2. Create `packages/client/src/composables/useGameSocket.ts`:
       - Import `useWebSocket` from `@vueuse/core`
       - Import `ClientMessage`, `ServerMessage` from `@shit-head/shared`
       - Create a composable that wraps useWebSocket with game-specific logic:
         - Determine WebSocket URL dynamically: in dev use `ws://localhost:3000/ws`, in production use `wss://${window.location.host}/ws` (detect via `import.meta.env.DEV`)
         - Actually, the Vite proxy already handles /ws -> server. So in dev, connect to `ws://${window.location.host}/ws`. In production same pattern with wss. Simplify: `const protocol = window.location.protocol === 'https:' ? 'wss:' : 'ws:'` then `${protocol}//${window.location.host}/ws`
         - Configure useWebSocket with: `autoReconnect: { retries: 5, delay: 1000, onFailed() { /* handle connection failure */ } }`, `heartbeat: { message: 'ping', interval: 30000, pongTimeout: 5000 }`
         - Expose reactive state: `status` (connecting, open, closed), `lastMessage` (parsed ServerMessage or null), `error` ref
         - Expose `send(msg: ClientMessage)` function that JSON.stringifies and sends
         - Expose `onMessage(callback: (msg: ServerMessage) => void)` for registering handlers — use a watch on the `data` ref from useWebSocket, parse JSON, validate type, call callback
         - Store `playerId` ref (set from room-created/room-joined responses)
         - Store `roomState` ref (updated from room-created/room-joined/room-updated/player-left responses)
         - Provide a singleton pattern or use provide/inject so all components share one socket
       - Export `useGameSocket` composable

    3. Create `packages/client/src/router.ts`:
       - Import `createRouter`, `createWebHashHistory` from `vue-router` (use hash history for simpler deployment — no server-side route handling needed)
       - Define routes:
         - `{ path: '/', name: 'landing', component: () => import('./components/Landing.vue') }`
         - `{ path: '/room/:code', name: 'lobby', component: () => import('./components/Lobby.vue') }`
       - Export the router instance
       - NOTE: Use `createWebHistory` instead of hash history if the Vite proxy handles all routes. Since this is a SPA, hash history is simpler and avoids 404s on refresh. Use `createWebHashHistory`.

    4. Update `packages/client/src/main.ts`:
       - Add `import { router } from './router'`
       - Add `app.use(router)` before `app.mount('#app')`
