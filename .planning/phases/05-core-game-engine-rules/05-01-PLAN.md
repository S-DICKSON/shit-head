<task type="auto">
  <name>Task 1: Add gameplay message schemas</name>
  <files>packages/shared/src/schemas/messages.ts</files>
  <action>
Add the following new schemas to the existing messages.ts file:

**Client-to-server schemas:**

1. `playCardsSchema` - Client sends card indices to play:
   ```
   { type: 'play-cards', cardIndices: number[] }
   ```
   - `cardIndices`: `z.array(z.number().int().min(0)).min(1)` (non-empty array of non-negative integers)

2. `pickupPileSchema` - Client requests to pick up the discard pile:
   ```
   { type: 'pickup-pile' }
   ```
   - No additional fields needed.

Add both to the `clientMessageSchema` discriminated union.

**Server-to-client schemas:**

3. `cardPlayedSchema` - Server broadcasts after a successful card play:
   ```
   { type: 'card-played', playerId: string, cards: Card[], currentPlayerIndex: number, drawPileCount: number, discardPile: Card[], hand?: Card[], opponents?: OpponentView[] }
   ```
   - `playerId`: z.string() (who played)
   - `cards`: z.array(cardSchema) (the cards that were played)
   - `currentPlayerIndex`: z.number() (whose turn it is now)
   - `drawPileCount`: z.number() (remaining draw pile)
   - `discardPile`: z.array(cardSchema) (updated discard pile state)
   - `hand`: z.array(cardSchema).optional() (updated hand for the playing player only)
   - `opponents`: z.array(opponentViewSchema).optional() (updated opponent views)

4. `pilePickupSchema` - Server broadcasts after a pile pickup:
   ```
   { type: 'pile-pickup', playerId: string, currentPlayerIndex: number, discardPile: Card[], hand?: Card[], opponents?: OpponentView[] }
   ```
   - `playerId`: z.string() (who picked up)
   - `currentPlayerIndex`: z.number() (next player)
   - `discardPile`: z.array(cardSchema) (should be empty after pickup)
   - `hand`: z.array(cardSchema).optional() (updated hand for pickup player)
   - `opponents`: z.array(opponentViewSchema).optional() (updated opponent views)

5. `turnChangedSchema` - Server notifies turn change:
   ```
   { type: 'turn-changed', currentPlayerIndex: number }
   ```
   - `currentPlayerIndex`: z.number()

Add all three to the `serverMessageSchema` discriminated union.

**Error code extension:**
Add `'NOT_YOUR_TURN'` to the errorSchema code enum for turn validation errors.
