**GameEngine.playCards(state: GameState, playerId: string, cardIndices: number[]): OperationResult&lt;GameState&gt;**

Validation errors (return success: false):
- `state.phase !== 'playing'` -> error: 'Can only play cards during playing phase', code: 'INVALID_ACTION'
- Player not found in state.players -> error: 'Player not found', code: 'PLAYER_NOT_FOUND'
- Player index !== state.currentPlayerIndex -> error: 'Not your turn', code: 'NOT_YOUR_TURN'
- cardIndices is empty -> error: 'Must play at least one card', code: 'INVALID_ACTION'
- Any index < 0 or >= player.hand.length -> error: 'Invalid card index', code: 'INVALID_ACTION'
- Duplicate indices in cardIndices -> error: 'Duplicate card indices', code: 'INVALID_ACTION'
- Cards at indices have different ranks (for multi-card play) -> error: 'All cards must have same rank', code: 'INVALID_ACTION'
- Card rank < top of discard pile rank (via canPlayOn) -> error: 'Card value too low', code: 'INVALID_ACTION'

Success behavior (return success: true with new GameState):
- Remove played cards from player's hand (by indices, handle removal carefully to avoid index shifting)
- Add played cards to end of discardPile
- Auto-draw: if player.hand.length < 3 AND drawPile.length > 0, draw cards from top of drawPile until hand has 3 or drawPile is empty
- Advance turn: currentPlayerIndex = (currentPlayerIndex + 1) % players.length
- Return new immutable GameState

Edge cases:
- Empty discard pile: any card is playable
- Draw pile empty: no auto-draw happens
- Playing last card(s) from hand: hand becomes empty, no draw if pile empty (endgame is Phase 7)

**GameEngine.pickupPile(state: GameState, playerId: string): OperationResult&lt;GameState&gt;**

Validation errors:
- `state.phase !== 'playing'` -> error: 'Can only pick up during playing phase', code: 'INVALID_ACTION'
- Player not found -> error: 'Player not found', code: 'PLAYER_NOT_FOUND'
- Player index !== state.currentPlayerIndex -> error: 'Not your turn', code: 'NOT_YOUR_TURN'
- Discard pile is empty -> error: 'No cards to pick up', code: 'INVALID_ACTION'

Success behavior:
- Add all cards from discardPile to player's hand
- Clear discardPile to empty array
- Advance turn: currentPlayerIndex = (currentPlayerIndex + 1) % players.length
- Return new immutable GameState
