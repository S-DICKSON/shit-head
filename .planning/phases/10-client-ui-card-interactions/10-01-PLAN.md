  <name>Task 1: Create usePlayingPhase composable</name>
  <files>packages/client/src/composables/usePlayingPhase.ts</files>
  <action>
Create `usePlayingPhase.ts` following the useSwapPhase.ts pattern (composable that wraps useGameSocket).

**State:**
- `selectedHandIndices: ref<Set<number>>(new Set())` — multi-card selection for hand
- `selectedFaceUpIndex: ref<number | null>(null)` — single face-up selection
- `selectedFaceDownIndex: ref<number | null>(null)` — single face-down selection

**Computed:**
- `isMyTurn: computed<boolean>` — checks if `roomState.value?.players` index matches `gameView.value?.currentPlayerIndex` for the current playerId. Use `roomState.value?.players.findIndex(p => p.id === playerId.value)` to get player's index, then compare with `gameView.value?.currentPlayerIndex`.
- `activeSource: computed<'hand' | 'face-up' | 'face-down'>` — returns 'hand' if hand.length > 0, else 'face-up' if faceUp.length > 0, else 'face-down'. This mirrors server-side determinePlaySource.
- `canClickHand: computed<boolean>` — `isMyTurn && activeSource === 'hand'`
- `canClickFaceUp: computed<boolean>` — `isMyTurn && activeSource === 'face-up'`
- `canClickFaceDown: computed<boolean>` — `isMyTurn && activeSource === 'face-down'`
- `hasSelection: computed<boolean>` — any cards selected (hand indices > 0, or faceUp selected, or faceDown selected)

**Actions:**
- `toggleHandCard(index: number)` — guard with `!canClickHand.value` return. If selection is empty, add index. If already selected, remove it. If not selected, check if card at index has same rank as first selected card — if yes add, if no return (ignore different rank). Use `gameView.value!.hand[index]` to get card and compare ranks. Helper: `cardRank(card: Card): string` returns `card.kind === 'standard' ? card.rank : 'joker'`.
- `selectFaceUpCard(index: number)` — guard with `!canClickFaceUp.value` return. Toggle: if same index selected, deselect; else select this index (only single selection for face-up, then play immediately via playSelectedCards).
- `selectFaceDownCard(index: number)` — guard with `!canClickFaceDown.value` return. Send `{ type: 'play-face-down', faceDownIndex: index }` directly (no selection state needed, blind play is immediate).
- `playSelectedCards()` — guard with `!isMyTurn.value`. For hand: extract sorted indices from selectedHandIndices, send `{ type: 'play-cards', cardIndices: indices }`, clear selection. For face-up: if selectedFaceUpIndex is not null, send `{ type: 'play-cards', cardIndices: [selectedFaceUpIndex.value] }`, clear selection.
- `pickupPile()` — guard with `!isMyTurn.value` return. Send `{ type: 'pickup-pile' }`.
- `clearSelection()` — clear all selection refs. Call this on gameView changes (watch gameView deep to auto-clear when server updates state).

**Watchers:**
- Watch `gameView` (deep: true) to call `clearSelection()` on any state update from server. This prevents stale selections after card-played, pile-pickup, etc.

**Return:** gameView, playerId, roomState, turnTimeRemaining, turnTimerPlayerIndex, selectedHandIndices, selectedFaceUpIndex, selectedFaceDownIndex, isMyTurn, activeSource, canClickHand, canClickFaceUp, canClickFaceDown, hasSelection, toggleHandCard, selectFaceUpCard, selectFaceDownCard, playSelectedCards, pickupPile, clearSelection.

Create `PlayerCards.vue` as a presentational component that renders the player's three card zones (hand, face-up, face-down) with selection states and action buttons.

**Props (via defineProps):**
- `hand: Card[]`
- `faceUp: Card[]`
- `faceDownCount: number`
- `selectedHandIndices: Set<number>`
- `selectedFaceUpIndex: number | null`
- `isMyTurn: boolean`
- `activeSource: 'hand' | 'face-up' | 'face-down'`
- `hasSelection: boolean`

**Emits (via defineEmits):**
- `toggle-hand-card(index: number)`
- `select-face-up(index: number)`
- `select-face-down(index: number)`
- `play-cards()`
- `pickup-pile()`

**Template structure (mobile-first, bottom of screen = player cards):**

1. **"Your Turn" indicator** — conditional banner above cards when `isMyTurn` is true:
   `<div v-if="isMyTurn" class="text-center text-yellow-300 font-bold text-sm mb-2 animate-pulse">Your Turn!</div>`

2. **Hand cards section** (with TransitionGroup for list animations):
   - Label: `<span class="text-xs text-green-300 uppercase tracking-wide">Hand ({{ hand.length }})</span>`
   - Wrap cards in `<TransitionGroup name="card-list" tag="div" class="flex justify-center gap-1 sm:gap-2 flex-wrap">`
   - Each card as `<button>` with key `cardKey(card)` (use suit+rank or joker-id for stable keys).
   - Card styling: `w-14 h-21 sm:w-16 sm:h-24 bg-white text-black rounded border-2 flex flex-col items-center justify-center text-xs sm:text-sm transition-all`
   - Selected state: `:class="selectedHandIndices.has(i) ? 'ring-2 ring-yellow-400 -translate-y-2 border-yellow-400 shadow-lg' : 'border-gray-300'"`
   - Disabled state when not active source: `:class="activeSource !== 'hand' ? 'opacity-40 cursor-not-allowed' : 'cursor-pointer hover:border-gray-400'"`
   - Card content: rank + suit symbol (reuse suitSymbol helper from SwapPhase pattern)
   - Click handler: `@click="$emit('toggle-hand-card', i)"`

3. **Face-up cards section:**
   - Label: `Face Up ({{ faceUp.length }})`
   - Same card button pattern but with single-select: `:class="selectedFaceUpIndex === i ? 'ring-2 ring-yellow-400 -translate-y-2 border-yellow-400' : 'border-gray-300'"`
   - Disabled when not active source: `activeSource !== 'face-up' ? 'opacity-40 cursor-not-allowed' : ...`
   - Click: `@click="$emit('select-face-up', i)"`

4. **Face-down cards section:**
   - Label: `Face Down ({{ faceDownCount }})`
   - Render `faceDownCount` card-back buttons (v-for n in faceDownCount, key 'fd-'+n):
   - Card back styling: `w-14 h-21 sm:w-16 sm:h-24 bg-blue-800 rounded border-2 border-blue-600 flex items-center justify-center text-lg text-blue-300`
   - Content: `?`
   - Disabled when not face-down source: `activeSource !== 'face-down' ? 'opacity-40 cursor-not-allowed' : 'cursor-pointer hover:border-blue-400'`
   - Click: `@click="$emit('select-face-down', n - 1)"` (convert 1-indexed to 0-indexed)

5. **Action buttons** (centered, below cards):
   - "Play" button: visible when `hasSelection`, styled `px-6 py-2 bg-yellow-500 text-black font-bold rounded-lg disabled:opacity-50`. Emit `play-cards`.
   - "Pick Up Pile" button: always visible during turn, styled `px-6 py-2 bg-red-500 text-white font-bold rounded-lg disabled:opacity-50`. Disabled when `!isMyTurn`. Emit `pickup-pile`.
