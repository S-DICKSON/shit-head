  <files>packages/server/Dockerfile</files>
  <action>
    Rewrite `packages/server/Dockerfile` to have three stages: `dev`, `client-build`, and `production`.

    **Stage 1: `base`** (unchanged)
    - FROM oven/bun:1 AS base
    - WORKDIR /app

    **Stage 2: `dev`** (keep exactly as-is for Docker Compose local development)
    - FROM base AS dev
    - Copy root package.json, bun.lockb, tsconfig.json
    - Copy packages/server/package.json and packages/shared/package.json
    - RUN bun install
    - Copy packages/server/ and packages/shared/ source
    - EXPOSE 3000
    - CMD ["bun", "--watch", "packages/server/src/index.ts"]

    **Stage 3: `client-build`** (NEW -- builds client assets)
    - FROM base AS client-build
    - WORKDIR /app
    - Copy root package.json, bun.lockb, tsconfig.json
    - Copy ALL package.json files: packages/client/package.json, packages/shared/package.json, packages/server/package.json
    - Copy client tsconfig files: packages/client/tsconfig.json, packages/client/tsconfig.app.json, packages/client/tsconfig.node.json
    - Copy packages/shared/tsconfig.json
    - RUN bun install --frozen-lockfile (need all deps including dev for Vite build)
    - Copy packages/client/ source and packages/shared/ source
    - WORKDIR /app/packages/client
    - RUN bunx vite build
    - Result: client assets in /app/packages/client/dist/

    **Stage 4: `production`** (REWRITTEN -- unified server + client)
    - FROM base AS production
    - WORKDIR /app
    - Copy root package.json, bun.lockb, tsconfig.json
    - Copy packages/server/package.json and packages/shared/package.json
    - RUN bun install --frozen-lockfile --production
    - Copy packages/server/ and packages/shared/ source
    - **COPY --from=client-build /app/packages/client/dist ./packages/client/dist** (copy built client assets)
    - EXPOSE 3000 (NOT 8080 -- unified port)
    - ENV NODE_ENV=production
    - ENV PORT=3000
    - CMD ["bun", "packages/server/src/index.ts"]

    Key changes from old Dockerfile:
    - Production stage now includes client-build as intermediate stage
    - Port changed from 8080 to 3000 (unified)
    - Comment updated: "WebSocket + API + static files" not "WebSocket + API only"
    - Client dist is copied into the expected path that index.ts checks: `../../client/dist` relative to server/src/

    The path `packages/client/dist` relative to `/app` means index.ts resolves `join(import.meta.dir, '../../client/dist')` which from `/app/packages/server/src/` goes up to `/app/packages/client/dist/`. This is correct.
