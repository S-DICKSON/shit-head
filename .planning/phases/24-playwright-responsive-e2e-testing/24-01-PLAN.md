  <action>
1. Create `packages/e2e/package.json`:
   ```json
   {
     "name": "@shit-head/e2e",
     "version": "0.0.1",
     "private": true,
     "type": "module",
     "scripts": {
       "test": "playwright test",
       "test:ui": "playwright test --ui",
       "report": "playwright show-report"
     },
     "devDependencies": {
       "@playwright/test": "^1.58.2"
     }
   }
   ```

2. Create `packages/e2e/playwright.config.ts` with:
   - `testDir: './tests'`
   - `fullyParallel: true`
   - `forbidOnly: !!process.env.CI`
   - `retries: process.env.CI ? 2 : 0`
   - `workers: process.env.CI ? 1 : undefined`
   - `reporter: [['html', { open: 'never' }]]`
   - `timeout: 30_000`
   - `use.baseURL: 'http://localhost:5173'`
   - `use.trace: 'on-first-retry'`
   - 6 projects: mobile-375 (iPhone SE device + 375x667 viewport), mobile-390 (iPhone 14 device + 390x844 viewport), tablet-768 (768x1024, hasTouch: false), laptop-1280 (1280x800), desktop-1920 (1920x1080), discord-iframe-460 (460x720)
   - `webServer` array with two entries:
     - Bun server: `command: 'bun run src/index.ts'`, `cwd: '../server'`, `url: 'http://localhost:3000'`, `reuseExistingServer: !process.env.CI`, `timeout: 30_000`, `env: { NODE_ENV: 'development', PORT: '3000' }`
     - Vite client: `command: 'bunx vite'`, `cwd: '../client'`, `url: 'http://localhost:5173'`, `reuseExistingServer: !process.env.CI`, `timeout: 60_000`
   - Use `import { defineConfig, devices } from '@playwright/test'` and spread `devices['iPhone SE']` / `devices['iPhone 14']` for mobile projects.

3. Create `packages/e2e/tsconfig.json`:
   ```json
   {
     "compilerOptions": {
       "target": "ES2022",
       "module": "ESNext",
       "moduleResolution": "bundler",
       "strict": true,
       "esModuleInterop": true,
       "skipLibCheck": true,
       "outDir": "./dist"
     },
     "include": ["tests/**/*.ts", "playwright.config.ts"]
   }
   ```

4. Create `packages/e2e/.gitignore`:
   ```
   playwright-report/
   test-results/
   blob-report/
   ```

5. Add 3 targets to Makefile (append after the existing `prod-local-down` target):
   ```makefile
   e2e: ## Run Playwright E2E tests (local, no Docker)
   	cd packages/e2e && bunx playwright test

   e2e-ui: ## Run Playwright E2E tests with UI mode
   	cd packages/e2e && bunx playwright test --ui

   e2e-report: ## Open last Playwright test report
   	cd packages/e2e && bunx playwright show-report
   ```
   Also add `e2e e2e-ui e2e-report` to the `.PHONY` line at the top of the Makefile.

6. Run `cd packages/e2e && bun install` from the monorepo root to install Playwright. Then run `cd packages/e2e && bunx playwright install chromium` to install browser binaries.

7. Create an empty `packages/e2e/tests/.gitkeep` file so git tracks the test directory.
  </action>

    - `grep "e2e:" Makefile` confirms target exists

  <name>Task 2: Create Page Object Models for all 4 screens</name>
  <files>

  <action>
Create 4 Page Object Model classes using role-based locators that match the actual Vue component markup. The app uses hash-based routing (`createWebHashHistory`), so URLs look like `http://localhost:5173/#/room/ABC123`.

**LandingPage.ts** — Maps to `Landing.vue`:
- `heading`: `page.getByRole('heading', { name: 'Karma' })`
- `nicknameInput`: `page.getByLabel('Your Nickname')` (matches `<label for="nickname">Your Nickname</label>`)
- `roomCodeInput`: `page.getByPlaceholder('ABC123')` (matches `placeholder="ABC123"`)
- `createRoomButton`: `page.getByRole('button', { name: /Create New Room/i })`
- `joinRoomButton`: `page.getByRole('button', { name: /Join Room/i })`
- `connectionStatus`: `page.getByText('Connecting to server...')`
- Methods:
  - `goto()` — `page.goto('/')`
  - `waitForConnected()` — wait for create button to be enabled (WS opens), use `await expect(this.createRoomButton).toBeEnabled({ timeout: 5000 })`
  - `fillNickname(name: string)` — fill nickname input
  - `createRoom(nickname: string)` — fill nickname + click Create New Room
  - `joinRoom(nickname: string, code: string)` — fill nickname, fill room code, click Join Room

**LobbyPage.ts** — Maps to `Lobby.vue`:
- `playersHeading`: `page.getByRole('heading', { name: /Players/i })` (matches `<h2>Players 1/4</h2>`)
- `leaveButton`: `page.getByText('Leave Room')` (the leave link in the header)
- `startGameButton`: `page.getByRole('button', { name: /Start Game/i })`
- `waitingMessage`: `page.getByText('Waiting for host to start...')`
- `roomCodeDisplay`: `page.locator('[data-testid="room-code"]')` — NOTE: RoomCode.vue may need a `data-testid`. If `RoomCode.vue` does not have `data-testid`, use `page.getByText(/[A-Z0-9]{6}/)` as a fallback locator for the room code.
- Methods:
  - `waitForLobby()` — wait for players heading to be visible
  - `getPlayerNames()` — return text content of player name elements
  - `getPlayerCount()` — extract count from heading text

**SwapPhasePage.ts** — Maps to `SwapPhase.vue`:
- `faceUpLabel`: `page.getByText('Face Up')`
- `handLabel`: `page.getByText('Your Hand')`
- `faceDownLabel`: `page.getByText('Face Down')`
- `readyButton`: `page.getByRole('button', { name: /Ready/i })`
- `leaveButton`: `page.getByRole('button', { name: 'Leave' })` (fixed top-left)
- Methods:
  - `waitForSwapPhase()` — wait for `faceUpLabel` visible
  - `getHandCardCount()` — count button elements in the "Your Hand" section
  - `getFaceUpCardCount()` — count button elements in the "Face Up" section

**GamePage.ts** — Maps to `PlayingPhase.vue` (rendered inside `Game.vue`):
- `leaveButton`: `page.getByRole('button', { name: 'Leave' })` (fixed top-left)
- `turnBanner`: `page.getByText("Your turn")` (from TurnBanner.vue)
- `drawPile`: `page.getByText(/Draw/i)` or use a `data-testid` if DrawPile has one. Check DrawPile.vue for accessible text. Fallback: `page.locator('[data-testid="draw-pile"]')`.
- `gameOverHeading`: `page.getByText('Game Over')`
- Methods:
  - `waitForGameScreen()` — wait for leave button visible in game context
  - `isOpponentVisible()` — check if any opponent card area is visible

All POM classes should:
- Import `type Page` and `type Locator` from `@playwright/test`
- Use `import { expect } from '@playwright/test'` where assertions are in helper methods
- Accept `Page` in constructor
- Use readonly fields for locators
- NOT import shared types (POMs are pure Playwright, no app dependencies)
  </action>

    - Each POM file exports a named class
    - Locators use `getByRole`, `getByLabel`, `getByText`, `getByPlaceholder` (not CSS selectors)
  </verify>
