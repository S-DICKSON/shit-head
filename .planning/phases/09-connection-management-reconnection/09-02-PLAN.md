    Add disconnect/reconnect lifecycle methods to Room.ts. Follow the existing callback pattern established by swap timer (setSwapCallbacks) and game callbacks (setGameCallbacks).

    **Add private properties** (after existing timer properties, around line 26):

    ```typescript
    private disconnectedPlayers: Map<string, {
      disconnectTime: number;
      gracePeriodTimer: ReturnType<typeof setTimeout> | null;
    }> = new Map();
    private readonly DISCONNECT_GRACE_PERIOD = 90000; // 90 seconds
    private onPlayerDisconnected?: (playerId: string, nickname: string) => void;
    private onPlayerReconnected?: (playerId: string, nickname: string) => void;
    private onPlayerRemoved?: (playerId: string, nickname: string, reason: 'timeout' | 'host-left') => void;
    ```

    **Add `setDisconnectCallbacks` method** (after `setGameCallbacks`):

    ```typescript
    setDisconnectCallbacks(callbacks: {
      onDisconnected: (playerId: string, nickname: string) => void;
      onReconnected: (playerId: string, nickname: string) => void;
      onRemoved: (playerId: string, nickname: string, reason: 'timeout' | 'host-left') => void;
    }): void {
      this.onPlayerDisconnected = callbacks.onDisconnected;
      this.onPlayerReconnected = callbacks.onReconnected;
      this.onPlayerRemoved = callbacks.onRemoved;
    }
    ```

    **Add `handlePlayerDisconnect(playerId: string)` method:**
    - Get the player from `this.players`. If not found, return.
    - If no active game (`!this.gameState || this.gameState.phase === 'finished'`):
      - This is a lobby/finished disconnect. Remove immediately:
      - Call `this.removePlayer(playerId)` (returns boolean for host check).
      - Determine if host: `playerId === this.hostId`.
      - Call `this.onPlayerRemoved?.(playerId, player.nickname, isHost ? 'host-left' : 'timeout')`.
      - Return early.
    - If active game (playing or swapping/transitioning):
      - Start grace period with `setTimeout` that calls `this.removePlayerAfterTimeout(playerId)` after `DISCONNECT_GRACE_PERIOD`.
      - Store in `this.disconnectedPlayers.set(playerId, { disconnectTime: Date.now(), gracePeriodTimer })`.
      - Call `this.onPlayerDisconnected?.(playerId, player.nickname)`.
      - **Turn timer interaction:** If it's the disconnected player's turn (`this.gameState.phase === 'playing' && this.gameState.players[this.gameState.currentPlayerIndex]?.playerId === playerId`), call `this.clearTurnTimer()` (method added by Phase 8-02).

    **Add `handlePlayerReconnect(playerId: string)` method:**
    - Get disconnect data from `this.disconnectedPlayers.get(playerId)`. If not found, return (player wasn't disconnected).
    - Clear grace period timer: `if (disconnectData.gracePeriodTimer) clearTimeout(disconnectData.gracePeriodTimer);`
    - Delete from map: `this.disconnectedPlayers.delete(playerId);`
    - Get player from `this.players`. If found:
      - Call `this.onPlayerReconnected?.(playerId, player.nickname)`.
      - **Turn timer interaction:** If it's the reconnected player's turn (`this.gameState?.phase === 'playing' && this.gameState.players[this.gameState.currentPlayerIndex]?.playerId === playerId`), call `this.startTurnTimer(this.gameState.currentPlayerIndex)` (method added by Phase 8-02).

    **Add `private removePlayerAfterTimeout(playerId: string)` method:**
    - Race condition safety: `if (!this.disconnectedPlayers.has(playerId)) return;` (player may have reconnected just before timeout fires).
    - Delete from disconnectedPlayers map.
    - Get player from `this.players`. If not found, return.
    - Check if host: `const isHost = playerId === this.hostId;`
    - If host:
      - Call `this.onPlayerRemoved?.(playerId, player.nickname, 'host-left')`.
      - Return (room destruction handled by the handler layer that receives this callback).
    - If non-host:
      - Call `this.removePlayer(playerId)`.
      - Call `this.onPlayerRemoved?.(playerId, player.nickname, 'timeout')`.
      - If game in progress and was removed player's turn:
        - Get `currentPlayer = this.gameState.players[this.gameState.currentPlayerIndex]`.
        - If `currentPlayer?.playerId === playerId`, advance turn: `this.gameState.currentPlayerIndex = GameEngine.nextActivePlayerIndex(this.gameState, this.gameState.currentPlayerIndex);`
        - Clear and restart turn timer: `this.clearTurnTimer(); this.startTurnTimer(this.gameState.currentPlayerIndex);`
        - Notify: `this.onPlayPhaseStart?.(this.gameState.currentPlayerIndex);`
      - Check if game should end (fewer than 2 active players):
        - Count active players: `const activePlayers = this.gameState.players.filter(p => p.hand.length > 0 || p.faceUp.length > 0 || p.faceDown.length > 0);`
        - If `activePlayers.length < 2`:
          - Set `this.gameState.phase = 'finished'`.
          - Call `this.clearTurnTimer()`.
          - The remaining active player (or last player) is the "winner" — the last eliminated is actually the loser.
          - If `activePlayers.length === 1`: call `this.onGameOver?.(activePlayers[0].playerId, activePlayers[0].nickname)` — this player is the shithead since they're the last one with cards.
          - If `activePlayers.length === 0`: edge case, use first player as fallback.

    **Add `isPlayerDisconnected(playerId: string): boolean` method:**
    - Return `this.disconnectedPlayers.has(playerId);`

    **Add `getDisconnectGraceRemaining(playerId: string): number` method:**
    - Get disconnect data. If not found, return 0.
    - Calculate: `Math.max(0, this.DISCONNECT_GRACE_PERIOD - (Date.now() - disconnectData.disconnectTime))`.
