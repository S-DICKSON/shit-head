    Replace the existing `handleClose` function body. The new logic:

    ```typescript
    export function handleClose(ws: ServerWebSocket<WebSocketData>, manager: RoomManager): void {
      // Always remove from active sockets (the WebSocket connection is dead)
      playerSockets.delete(ws.data.playerId);

      const roomCode = ws.data.roomCode;
      if (!roomCode) return;

      const room = manager.getRoomByPlayerId(ws.data.playerId);
      if (!room) return;

      // Delegate to Room's disconnect handling (grace period for in-game, immediate for lobby)
      room.handlePlayerDisconnect(ws.data.playerId);

      // Note: Do NOT call manager.leaveRoom() here anymore.
      // Room.handlePlayerDisconnect handles everything:
      // - For lobby: removes immediately and fires onPlayerRemoved callback
      // - For in-game: starts grace period, fires onPlayerDisconnected callback
      // The callbacks (wired in start-game handler) handle broadcasting to other players.
      // Room destruction on host leave is handled by the onPlayerRemoved callback.

      ws.unsubscribe(roomCode);
    }
    ```

    **2. Wire disconnect callbacks in the `start-game` handler:**

    In the `start-game` case, inside the `setTimeout` callback (the 3-second countdown block), add `room.setDisconnectCallbacks(...)` AFTER `room.setGameCallbacks(...)` and BEFORE `room.startGame()`:

    ```typescript
    room.setDisconnectCallbacks({
      onDisconnected: (disconnectedPlayerId, nickname) => {
        // Broadcast player-disconnected to all CONNECTED players in room
        const playerIds = room.getPlayerIds();
        const graceTime = room.getDisconnectGraceRemaining(disconnectedPlayerId);
        for (const pid of playerIds) {
          // Skip the disconnected player (their socket is already gone)
          if (pid === disconnectedPlayerId) continue;
          const pWs = playerSockets.get(pid);
          if (pWs) {
            sendMessage(pWs, {
              type: 'player-disconnected',
              playerId: disconnectedPlayerId,
              nickname,
              graceTimeRemaining: graceTime,
            });
          }
        }
      },
      onReconnected: (reconnectedPlayerId, nickname) => {
        // Broadcast player-reconnected to all other players
        const playerIds = room.getPlayerIds();
        for (const pid of playerIds) {
          if (pid === reconnectedPlayerId) continue;
          const pWs = playerSockets.get(pid);
          if (pWs) {
            sendMessage(pWs, {
              type: 'player-reconnected',
              playerId: reconnectedPlayerId,
              nickname,
            });
          }
        }
      },
      onRemoved: (removedPlayerId, nickname, reason) => {
        if (reason === 'host-left') {
          // Host timed out — room is destroyed. Notify all remaining connected players.
          const playerIds = room.getPlayerIds();
          for (const pid of playerIds) {
            if (pid === removedPlayerId) continue;
            const pWs = playerSockets.get(pid);
            if (pWs) {
              sendMessage(pWs, {
                type: 'player-removed',
                playerId: removedPlayerId,
                nickname,
                reason: 'host-left',
              });
            }
          }
          // Destroy room via manager
          manager.destroyRoom(room.code);
        } else {
          // Non-host timed out — broadcast removal to remaining players
          const playerIds = room.getPlayerIds();
          for (const pid of playerIds) {
            if (pid === removedPlayerId) continue;
            const pWs = playerSockets.get(pid);
            if (pWs) {
              sendMessage(pWs, {
                type: 'player-removed',
                playerId: removedPlayerId,
                nickname,
                reason: 'timeout',
              });
            }
          }
          // Also remove from playerRoomIndex since player is gone
          manager.removePlayerIndex(removedPlayerId);
        }
      },
    });
    ```

    The disconnect callbacks need to be set BEFORE the game starts too, because players can disconnect during lobby. However, during lobby, the `handlePlayerDisconnect` method does immediate removal which fires `onPlayerRemoved`. So the callbacks also need to handle lobby-phase disconnects.

    The simplest approach: set disconnect callbacks when the room is CREATED, not just at game start. Modify the `create-room` and `join-room` handlers to set initial disconnect callbacks (or set them once at game start since lobby disconnects already work via the existing leave mechanism).

    Actually, re-read the Room.handlePlayerDisconnect logic: for lobby (no gameState), it calls removePlayer and onPlayerRemoved. But the existing handleClose already handles lobby disconnects by calling manager.leaveRoom() and broadcasting room-updated. So we have two options:

    **Option A (simpler):** Only wire disconnect callbacks at game start. In handleClose, check if the room has an active game. If no game, use the existing lobby disconnect logic (call manager.leaveRoom, broadcast room-updated). If game is active, delegate to Room.handlePlayerDisconnect.

    Go with Option A. Update handleClose:

    ```typescript
    export function handleClose(ws: ServerWebSocket<WebSocketData>, manager: RoomManager): void {
      playerSockets.delete(ws.data.playerId);

      const roomCode = ws.data.roomCode;
      if (!roomCode) return;

      const room = manager.getRoomByPlayerId(ws.data.playerId);
      if (!room) return;

      const gameState = room.getGameState();

      if (gameState && gameState.phase !== 'finished') {
        // In-game disconnect: delegate to Room's grace period logic
        room.handlePlayerDisconnect(ws.data.playerId);
        ws.unsubscribe(roomCode);
      } else {
        // Lobby or finished game: use existing immediate removal logic
        const isHost = room.getState().hostId === ws.data.playerId;

        if (isHost) {
          // Notify others before destroying room
          ws.publish(roomCode, JSON.stringify({
            type: 'error',
            message: 'Host disconnected — room closed',
            code: 'ROOM_NOT_FOUND',
          }));
        }

        manager.leaveRoom(ws.data.playerId);
        ws.unsubscribe(roomCode);

        // Non-host disconnect — room still exists, notify remaining players
        if (!isHost) {
          const updatedRoom = manager.getRoom(roomCode);
          if (updatedRoom) {
            ws.publish(roomCode, JSON.stringify({
              type: 'room-updated',
              room: updatedRoom.getState(),
            }));
          }
        }
      }
    }
    ```

    This preserves the existing lobby disconnect behavior while adding grace period for in-game disconnects.

          code: 'ROOM_NOT_FOUND',
        });
        return;

      // Check if this player was in this room
      const roomState = room.getState();
      const playerInRoom = roomState.players.some(p => p.id === ws.data.playerId);

      if (!playerInRoom) {
        sendMessage(ws, {
          type: 'error',
          message: 'You are not in this room',
          code: 'PLAYER_NOT_FOUND',
        });
        return;
      }

      // Update connection data
      ws.data.roomCode = message.roomCode;
      ws.subscribe(message.roomCode);
      playerSockets.set(ws.data.playerId, ws);

      // Handle reconnection in room (clears grace period timer)
      room.handlePlayerReconnect(ws.data.playerId);
